## 3. 候補ID・共通の記録条件

- **F001〜F097**：総覧の候補識別子。**C001以降**：実機への具体的な確認依頼・結果の識別子。対応する既存C番号を表に示す。新しいC番号は実際に少数のケースを提示するときに割り当てる。
- 重点＝曲線・勾配・方向・長さの代表収集、境界＝成功／拒否・不成立の比較、拡張＝代表確認後の追加候補、関連＝分岐・駅・特殊接続等の関連候補。この優先区分もAI提案であり、対応決定ではない。
- 原則ENV-002：Minecraft 1.20.1／Forge 47.4.10／Create v6.0.8、既存の関連アドオン、CATなし、Create標準線路・標準軌間、クリエイティブ、maxTrackPlacementLength=128。撮影条件は視野角100。設定・版変更は別環境IDにする。
- 候補段階で各F項目に共通する未記入欄：**実端点位置・向き・高低差＝未設定、画像＝未受領、エラー＝未確認、敷設結果＝未試行、個別のCAT要望＝未確認**。既存C対応項目は形状一覧の記録を参照し、成功や座標を上書きしない。
- 表の寸法は実験条件だけを示す。実鉄道のm・‰をMinecraftへそのまま移して採用値にしない。曲率・局所勾配・長さ・接続連続性は画像だけで確定しない。
- 具体試行に進むときは、目的、形状、使用線路、端点位置・水平軸／傾斜・接続側、高低差、設定、操作、結果、画像・エラー、希望、技術未確認、要件側判断をC記録にそろえる。
- 直線・曲線の複数区間をつなぐ配置と、一回の接続操作で生成される一つの形を区別する。分割すると形が変わるなら、端点が同じでも「同一形状で成功」とは記録しない。
- 実鉄道の緩和曲線・円曲線と、Createが生成した曲線が数理的に同じとは仮定しない。「実配置／図」は、操作可能な部分を試し、操作自体がない部分は希望図へ回すという意味。

## 5. 全候補に横断して確認する条件

全条件の総当たりは行わない。まず代表形を一つ作り、差がありそうな条件を一つだけ変える。左右反転・回転・上り下りの見方が同一配置を表す場合は同じ形状群へまとめる。格子・方角依存や選択順による差が実際に出た場合だけ、派生試行を追加する。

| 条件 | 比較・記録する内容 | 記録上の注意 |
| --- | --- | --- |
| 端点の水平軸 | X、Z、斜め、任意角候補 | 方角、接線、列車の向きを混同しない |
| 端点の傾斜 | 水平、同じ傾斜、異なる傾斜 | 両端高低差だけで途中勾配を決めない |
| 位置・距離 | 短い／長い、対称／非対称、前方／横ずれ | 端点距離と実際の曲線長を区別 |
| 高さ | 同高、上側、下側、途中の頂上／谷 | 同じ端点でも途中形状が一意とは限らない |
| 曲がり方 | 同方向、反対向き、きつさの変更、緩和 | 半径値がない段階では見た目の分類と明記 |
| 選択順・側 | A→B／B→A、端点のどちら側を使うか | 見た目の反転と操作差を分離 |
| 補助キー | Shift等の有無 | 現状はShiftなしを基準。名称・操作効果を推測しない |
| 敷設単位 | 一括、複数接続、後から継足し | 生成形・継ぎ目・一括長制限を分離 |
| 有効設定 | 128を基準、必要なら32等との対照 | 設定値と敷設できた実長を同じものにしない |
| 支持・障害物 | 端点支持、途中の支持、既設線路との干渉 | 形状拒否と支障物・配置面由来の拒否を分離 |
| 線路種・軌間 | Create標準→同軌間アドオン、CAT希望図 | 等級と軌間は別。異軌間変換は承認範囲外 |
| 継ぎ目の状態 | 新設端、既存端、撤去後、既設曲線・分岐端 | 位置が触れているだけで接続成立としない |
| プレビューと確定 | 表示形、拒否文字、確定後の形 | 拒否段階を記録。プレビューのみで成功にしない |
| 設定・接続先の途中変更 | 表示後に条件が変わった場合 | CATでは再確認の方針あり。今回は希望・判断事項を収集し、実装検証はしない |
| 読込・再読込 | 必要時のみ、保存後の形状維持 | 別途具体依頼して扱う。現時点で新たに試行を依頼していない |
| 撮影 | 上方、側方、両端、エラー | 視野角100と遠近感を記録し、手前の広がりを軌間変更にしない |

## 6. 拒否・操作不能・希望形状の扱い

- **敷設成功**：確定後の配置画像と実座標を残す。今回の総覧作成で新たな成功例を追加したわけではない。
- **敷設拒否**：端点・支持面・プレビュー・エラー原文・拒否段階を残す。全ての拒否を曲率／勾配超過と断定しない。
- **操作方法がない／分からない**：未試行とし、「操作不能と確認」「方法未確認」を分ける。カント、任意角、指定した縦曲線・らせん等はこの区分になり得る。
- **図で表す希望**：元画像から分けた図・描き込みで意図を示す。描いた形をMinecraftで作れた記録にしない。実鉄道参考図とCATの希望図も区別する。
- **経路が不成立の候補**：位置・向き・軌間・自己交差等を記録し、拒否結果と利用者の希望を分ける。「CATで全て通す」という要件にしない。
- **走行可能性**：敷設成功と独立した未確認事項。幾何通過・登坂・下り停止・途中再起動・保持・乗り心地を別々に扱い、今回の形状収集を安全走行の試験と呼ばない。
