## 2. 公開資料で確認した範囲と限界

### 2.1 国・建設主体

国交省の「鉄道の技術基準の整備」の掲載資料を起点に、2026-03-31最終改正の解釈基準別冊1の線形・軌道・構造物・留置に関する箇所、掲載された定期検査告示の施設周期を確認した。解釈基準の具体値と省令の性能規定を分けた。JRTTの2021年10月公開版は、適用主体のある比較例として確認した。

設計標準書は参照先・公開紹介の範囲を確認したが、現行標準書全巻の本文・照査係数は入手していない。e-Govの省令ページは今回の閲覧では本文を抽出できず、その閲覧結果だけから条文を追加引用していない。災害防止設備は、本文確認できたB01第34条とJRの取組資料を根拠にした。

### 2.2 JR東日本・鉄道総研

JR東日本のTechnical Reviewの該当論文、E353系の公式発表、レーダ雨量導入発表、運賃改定の補足説明資料、公開の強風・降雨・浸水・地震対策ページ、雪の巡回補助開発ページを確認した。鉄道総研は締結荷重・橋上ロングレールの公開研究紹介と2026年施設研究ニュースを確認した。

検索・確認対象には、曲線半径／カント／不足カント／車体傾斜、等級／軸重／通過トン数、分岐器／低速脱線、勾配／等価査定、軌道変位／保守、熱座屈、風雨雪・地震が含まれる。JR現行全社の管理値を網羅する一次資料は確定できず、得られた個別実例・研究条件に範囲を限定した。旧国鉄の等級表や二次解説で不足を埋めていない。

JRの2026年グループレポートのサステナビリティPDFは閲覧容量上限、直接取得はアクセス拒否で本文未確認。読めた個別の取組ページを使用した。JR論文はWebで本文抽出を確認できたが、ローカル取得はアクセス拒否となり、ローカル画像照合をしていない。読めない資料は、閲覧済みの本文根拠に数えない。

No.67は検索側の年表示と論文本文ヘッダーの年が異なったため、本文の2022年を記録した。2021年度からの材料選択の報告と、2022年の刊行年を混同していない。URLに2026を含む運賃資料R13も、発表日の2025-08-01を採用した。

### 2.3 Create・CAT

提供済み`vendor/Create-mc1.20.1-6.0.8`の版・12ファイルを静的確認し、主要4ファイルのSHA-256を記録した。外部コードは取得していない。他アドオンの同名機能や変更を、標準Createの結果から推定していない。

CATは現在の`整理3.md`の関係節を確認した。今回の承認は調査範囲への承認であり、過去の実装・未承認案を現行仕様へ戻す根拠にはしていない。Minecraftの実挙動・大規模線路性能・処理遅延・サーバー／クライアントの同期到達順は未検証。

## 4. CATの検討へ渡す未決定事項

次に仕様を決める際、特に必要な選択は次のとおり。これは追加調査・実装を既に承認したリストではない。

1. 線路強化で変える性能。線形・材料・支持・保守・環境対策・車両側耐久の関係を明示する。
2. ゲームの尺度と簡略化。標準の1:1斜面、短い曲線、任意車体を実鉄道値へどう対応させるか。
3. 車両条件。質量・積載・固定軸距・重心・車体寸法・制動性能をどこまで扱うか。
4. 線路算定値の担当範囲。制御への速度上限、進入可否、脱線系原因を区別し、標識・信号・ATOSとの責務を選ぶ。
5. 情報状態と境界。未知／不存在、先頭／後尾、方向、分岐経路、形状変更・交換時の継承を定める。
6. 操作・保存・同期・表示。対象を確認できる選択方法、資源・権限、更新の正本、旧データ・既存ワールドの扱いを定める。

現行の列車側脱線系耐久、明示復旧、物理制限不明時の保留、有限の停止保持などは、今回の調査結果によって自動変更しない。
