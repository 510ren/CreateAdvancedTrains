# 線路敷設条件と線路強化の調査

調査日：2026-10-11。**指定25項目の公開資料・提供済みソース調査と出典照合を完了**。資料不足による未確認事項、CATの未決定事項は残る。CATの要件・仕様の採用決定ではない。

## 目的と読み方

線路強化を検討するため、実鉄道の敷設条件、構造・保守・環境条件、手元のCreate 6.0.8ソースで確認できる挙動を調べる。利用者が指定した25項目を維持し、4・5・16は概要、その他は詳細に扱う。項目の調査承認は、その機能をCATへ実装する承認とは区別する。

「制限強化」は許容速度の低下、「線路強化」は線路性能を改善する機能の検討を指す。既存の脱線系耐久値は列車側のCAT仕様であり、実鉄道の軌道の劣化や耐荷力と同じ量ではない。

根拠を次の5区分で記録する。

1. **国**：省令・告示と、数値を具体化する解釈基準。両者の拘束性も区別する。
2. **実施基準**：事業者・建設主体の公表基準。適用主体・版を必ず残す。
3. **実例・研究**：JR東日本等の特定線区・試験・研究報告。全社共通の現行規則へ一般化しない。
4. **ローカルソース**：vendor内の対象版の静的調査。Minecraftでの動作確認とは区別する。
5. **CAT検討**：上記から得られる論点・提案・未決定事項。採用値を独断で確定しない。

## 調査から得られる主な判断材料

- **最小曲線半径と設計速度は別**。国の新幹線400 mという基準値と、JRTT公開版の通常設計4,000 mは、資料の位置付け・条件が異なる。ホーム・分岐・車両通過性能にも別条件がある。
- **カントは大きいほど無条件に有利ではない**。不足側だけでなく低速・停止時の超過側、重心・風、逆カントになる分岐経路を扱う必要がある。
- **強化しても残る制約を分ける**。材料耐力を上げても、幾何通過限界、勾配抵抗、空間不足、運転許可が自動的に解消する根拠は得られなかった。
- **Createの半径値はそのまま使えない**。`getRadius()`は曲線全体の局所最小半径を保証しない。ピッチの平滑化も、実鉄道の左右カント値と同じではない。
- **CATとの接続は未決定**。線路算定値を物理制限・列車側耐久へ組み込むか、強化の効果・対象・操作・保存・同期をどう定めるかは、今回の根拠を基に選ぶ必要がある。
