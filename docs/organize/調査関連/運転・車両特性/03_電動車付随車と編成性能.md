# 電動車（M）・付随車（T）と編成性能の調査

- 対象：調査一覧の **3. 電動車M・付随車T、MT比**
- 調査日：2026-10-22（日本時間）
- 対象：公開一次資料の実車事例、提供済みCreate 6.0.8ソース、2026-10-21保存版の整理3.md。
- 検証範囲：文献・静的ソース確認。CAT実装、ビルド、Minecraft走行試験は行っていない。
- 本文の「考察」「案」は未承認。既存の性能プロファイルを変更する決定ではない。

## 1. 要点

M/Tの区別は、編成内の駆動能力と質量を整理するために使える。ただし、**MT比だけから加速度・最高速度・停止距離を一意には決められない**。同じ比率でも電動機出力、駆動軸荷重、車両質量、走行抵抗、制御方式などが異なり得る。これは下記の実車資料と力学的な整理からの結論である。

CATでは、まず「M/Tを編成情報として表示する」ことと「M/T構成から実性能を算出する」ことを分けて検討できる。後者を採るなら、プロファイルの意味、連結・分離後の性能、制動予測まで影響する。[再調査:CAT]

## 3. 実鉄道で確認できたこと

### 3.1 M/Tと主回路の単位

本書ではMを主電動機による駆動を担う電動車、Tをその駆動を担わない付随車として扱う。運転台の有無や集電装置の有無まで、M/Tの一文字だけで決めない。

**事実**：JR東日本のE235系量産先行車の紹介では、11両編成6M5T、独立M車方式、1両につき1台の制御装置、1C4M制御が示される。同記事は編成構成の自由度と、効率のよい条件で動作させるための稼働主電動機数制御を説明している。[R1]

**読み取れる限界**：この資料は量産先行車の主回路の説明である。すべてのE235系番台・後年改造の構成、各ノッチの実加速度、故障時の性能を確定する資料ではない。M車数が同じなら常に同じ数の電動機が同じ出力で働く、ともいえない。

### 3.2 加速能力には車輪・レール間の条件も関係する

**事実**：鉄道総研は、主電動機のトルクが歯車・車輪を介してレールとの接線力となり加速する過程を説明している。雨雪時等の空転では加速性能が低下し、トルクを下げて再粘着を図る制御がある。[R2]

**導出**：M車を増やすと増えるのは車両数だけではない。質量、駆動可能な軸の荷重、電動機・変換装置の能力も変わる。このため、M車比率をそのまま加速度の倍率にする方法は、同一機器・同程度の車両質量等の追加前提を必要とする。

### 3.3 T車にも制動を考える必要がある

**事実**：鉄道総研のブレーキ力評価研究では、動台車側の電気ブレーキ情報と、従台車側の空気ブレーキを分けて扱う。BC圧と摩擦力が常に単純比例するわけではない点も説明される。[R3]

したがって、一般的な電車を参考にするCAT案として「T車は駆動しないのでブレーキもない」と置く根拠はない。一方、どの車両の電気・空気ブレーキをどの順で負担させるかは車両方式別に確認が必要で、本調査から全形式共通の配分規則は確定できない。

## 4. 仕様から独立して残せる力学的整理

以下は、編成を一つの剛体的な質点として扱い、車両間の伸縮振動を無視した**説明用モデル**である。当該進行方向へ走行中（\(v>0\)）の式に限定し、逆転・停止保持には別の符号処理が必要である。CATの採用式ではない。

\[
m_{\mathrm{eq}}\frac{dv}{dt}
=\sum F_{\mathrm{traction},i}-\sum F_{\mathrm{brake},i}
-R(v)-\sum_i m_i g\sin\theta_i
\]

- \(v\)：進行方向を正とする速度［m/s］。
- \(m_{\mathrm{eq}}\)：回転部分の慣性を必要に応じて等価質量として含む量［kg］。含めない近似ならその前提を残す。
- 各\(F\)と\(R\)：力［N］。力行・制動・抵抗を二重計上しない。
- \(\theta_i\)：車両位置の上りを正とした勾配角。長編成が異なる勾配をまたぐ場合は一地点の勾配で置き換えた誤差が生じる。

低速側の粘着上限を概念的に\(F\leq\mu W_{\mathrm{driven}}\)、動力側の出力上限を\(Fv\leq P\)と整理できる。\(W_{\mathrm{driven}}\)は駆動軸に作用する法線荷重［N］、\(P\)は車輪側で利用できる動力［W］である。ただし\(\mu\)は固定の実車定数ではなく、\(P/v\)を停止時まで適用して無限大の力を与えることもできない。低速域と高速域を分ける必要がある。[R2を踏まえた導出]

同じMT比でも、上式の質量・力・抵抗が違えば運動は変わる。逆に、プロファイルが既に「抵抗込みの編成実加速度」を表すなら、後からM/T補正・質量補正を加えると同じ要因を二度反映するおそれがある。[再調査:CAT]

## 6. 現在のCATとの照合 [再調査:CAT]

整理3.md第4.1節は速度依存のP曲線、第5章は組立時に選ぶ列車単位の性能プロファイルを定める。第5.5節では編成変更後の性能・版等の継承が未決定である。[C1]

| 現在の枠組み | M/T導入で増える判断 |
|---|---|
| プロファイルを組立時に選び、内容を列車へ保存 | プロファイルが完成編成の性能か、M/T算定用の部品定義かを分ける。 |
| 同版プロファイルは共通性能 | 同版でもMT比が違う列車に異なる実性能を認めるか。認めるなら現在の「共通性能」の意味を改めて定義する。 |
| CAT独自連結・分離を追加予定 | 継続側プロファイルの維持、車両情報からの再計算、混成禁止等の比較が必要。 |
| 最終常用段とEBは同じ減速度 | M/Tや回生の可否が常用・非常へ別々に影響する案は、この決定との整合確認が必要。 |

## 7. CATで検討する案とMinecraftの兼ね合い

### 7.1 再現の深さを選ぶ [再調査:CAT]

| 案 | 利点 | 制約・追加負担 |
|---|---|---|
| 編成情報だけM/Tを持ち、性能は従来プロファイル | 表示・音源位置等へ使え、既存性能との接続が小さい | M/T変更が加速へ反映されないことを明示する必要がある。 |
| MT比・編成質量等を使う簡略補正 | 編成構成の意味をゲームに出しやすい | 補正式の根拠、基準編成、上下限、抵抗の二重計上を検証する。 |
| 車両／台車の力・質量を集計 | 混成、M故障、分離後性能を説明しやすい | 保存・ID・性能算定・停止予測・設定UIが大きく増える。細かいほど実車に正確とは限らない。 |

**考察**：装飾ブロック数をそのまま実車質量へ変えると、内装変更が運転性能を大幅に変える可能性がある。固定車両質量、車両定義値、ブロック由来値のどれを採るかはゲーム設計の判断になる。M/T比だけを入力する場合でも、総両数、車両ごとの役割、故障状態をどう対応させるかが残る。

### 7.2 計算と識別 [再調査:CAT] [再調査:実機]

車両別情報を採用しても、毎tick全ブロックを走査する必要があるとは限らない。組立・編成変更時に集計し、運転中は速度・勾配・故障に応じた量だけ更新する案を比較できる。ただし、変更検知とキャッシュ失効の成立は未検証である。

最低限の検証候補は、同一プロファイルでM/Tだけ変更した編成、同MT比で長さを変えた編成、Mだけを分離した編成、異なる勾配をまたぐ編成、M故障とブレーキ故障を分けた編成である。各ケースで加速・停止予測・HUD・保存再開が同じ性能を参照するかを見る。

## 8. 不明点・追加資料

- E235系を基準にする場合の番台、編成、荷重条件、ノッチ別引張力・制動性能は未確定。公開資料だけで完全な性能表は得られていない。
- CATの車両質量、M/T設定単位、故障時の駆動能力低下、混成編成の許可条件は未決定。
- Createの車両識別・保存・CAT独自連結への具体的な実装方法は本書では確定していない。
- 実車の詳細性能へ合わせる段階では、対象車種の仕様表・主回路特性・ブレーキ特性を利用者に提示してもらうと絞り込める。現在の比較資料作成を止める必須条件ではない。
