# ワンハンドルマスコンのノッチとレバーサー位置の関係

- 作成日：2026-09-30
- 元調査：本チャットで2026-09-29～30に確認した公開資料と説明
- 文書区分：実車調査・参考資料。CATの承認済み要件や実装仕様ではない。
- 優先調査対象：JR東日本 E233系・E235系
- 表の参考車種：**東急8500系（新玉川線・営団半蔵門線直通仕様）**

## 1. 結論と適用範囲

E233系・E235系の主幹制御器について、ノッチと逆転ハンドルの全組合せ、速度条件、機械的・電気的インターロックを確定できる公開取扱説明書・仕様書は、今回の調査では確認できなかった。

そこで、東急公開の『新玉川線建設史』に収録された直通車両仕様を参考に、停止／走行 × EB・B・N・P × レバーサー前・中・後の24通りを整理する。[S1]

参考方式の主要な操作条件は次のとおり。

1. 主ハンドルが**EB（非常）位置のときに、レバーサーを切り替える**。
2. レバーサーが**前・後のときに、主ハンドルをEB～Pの範囲で操作できる**。
3. レバーサーが**中（資料中の「切」）では、主ハンドルをEBからB・N・P側へ動かせない**。
4. 主ハンドルが**B・N・Pでは、レバーサーを中立や反対方向へ動かせない**。

これらの操作条件は東急の仕様に基づく。日立の特許に記載された従来型主幹制御器でも、同様の関係が「機械的インターロック」として説明されている。ただし、この特許は東急8500系への納入や、その内部機構の具体的構造を証明するものではない。[S1][S2]

**この表を、E233系・E235系や日本の全ワンハンドル車に共通する確定仕様として適用してはならない。**

## 2. 根拠の分類

| 区分 | 意味 | 本文での対象 |
|---|---|---|
| 資料明記 | 出典に直接記載された条件 | 主ハンドルと逆転ハンドルの操作可能位置 |
| 条件からの整理 | 資料の条件を組合せ表へ展開した結果 | 中＋B・N・Pが正常な操作では成立しないこと |
| 一般的作用・推論 | 指令の通常の意味や、記載条件から推論した作用 | 停止中Pでの起動、Nでの惰行、走行中EBでのレバーサー操作可能性 |
| 未確認 | 車種固有の資料が不足している事項 | 速度連動ロック、逆方向力行時の保護、E233系・E235系の同一条件採用 |

表は24ケースを実車で試験した結果ではない。機構の操作条件と車両の動的な反応は、根拠の強さを分けて読む必要がある。

## 3. 用語と前提

| 表記 | 意味 |
|---|---|
| 主ハンドル | 力行とブレーキを操作するワンハンドルのレバー |
| レバーサー | 前・中・後を選択する逆転ハンドル |
| EB | 主ハンドルの非常ブレーキ位置。非常ブレーキ指令 |
| B | 常用ブレーキ各段の総称 |
| N | 主ハンドルの中立・切位置 |
| P | 力行各段の総称 |
| 前・後 | 操作する運転台を基準とする方向選択。現在の実際の進行方向とは別 |
| 中 | レバーサーの中立。出典の「切」に対応し、主ハンドルのNとは別 |
| 操作不可 | インターロックによりハンドルそのものを目的の位置へ動かせないこと |
| ロック | 指定された側のハンドルの移動が拘束されること。両ハンドルが同時に動かなくなるとは限らない |

以下を前提とする。

- キーによる解錠を済ませた、使用中の運転台を想定する。
- 正常な機構を想定し、強制解除、故障、改造、検修扱いは含めない。
- 力行については、戸閉め・電源・保安装置などの別条件も満たす必要がある。表はそれらを網羅した起動許可表ではない。
- ブレーキの反応は、装置・空気供給などが正常な場合の通常作用として記載する。
- ATS・ATC等の自動介入や、他運転台からの指令は独立した条件として扱う。
- 「停止中」は観察した時点で速度がゼロであることを指す。停止を維持する制動力があることまでは意味しない。
- EBはここではノッチ名であり、運転士の無操作監視を行うEB装置の意味ではない。

### ※1 走行中EBでのレバーサー操作

[S1]は切替条件として主ハンドルの非常位置を挙げているが、その箇所には速度ゼロという条件を記していない。その記載条件だけからは走行中も切替可能と読めるため、表では**推論として「条件上は可」**とした。

これは、別の速度連動ロックが存在しないことを確認したという意味ではない。走行中に実車で操作した検証でもない。**機構上の操作可能性、車両制御側の指令受付、運転取扱上の許可は別**であり、走行中の切替を許可する手順としては扱わない。

### ※2 実際の進行方向とレバーサーの不一致

「走行中・P・後」には、後進中に後方向へ力行する通常状態と、前進中に後方向へ力行を指令する状態が含まれる。24通りだけでは実際の進行方向を区別できず、後者の作用は一意に決まらない。

逆方向への力行指令について、主回路が拒否するか、保安装置が介入するか、逆向きのトルクを発生するか、およびその速度条件は今回未確認である。**「何も起きない」「減速する」「非常ブレーキが掛かる」のいずれも確定しない。**

Bについても、実際の進行方向と選択方向が不一致の場合の回生ブレーキの可否・空気ブレーキとの分担は未確認である。

## 5. 「操作不可」「ロック」「動かせるが作用しない」の区別

### 5.1 操作不可はハンドルそのものを動かせないという意味

| 現在の状態 | 動かせないハンドル・操作 | 次に必要な操作 |
|---|---|---|
| レバーサー中＋主ハンドルEB | 主ハンドルをEBからB・N・P側へ動かせない | 主ハンドルをEBに置いたまま、レバーサーを前・後へ動かす |
| 主ハンドルB・N・P＋レバーサー前・後 | レバーサーを中立や反対方向へ動かせない | レバーサーをそのままにして、主ハンドルをEBへ戻す |

したがって、中＋B・N・Pは、操作できた後で電気的に無効化される状態ではなく、正常な操作では到達できない組合せとして整理している。[S1][S2]

### 5.2 全操作を一括でロックするわけではない

B・N・Pでレバーサーがロックされていても、主ハンドルをEBへ戻す操作は可能である。逆に、EB＋中で主ハンドルのB側への移動が拘束されていても、キーの解錠条件を満たしたレバーサーの操作は可能である。

### 5.3 レバーサーを動かしても、EBは解除されない

EBを維持したままレバーサーだけを前・中・後へ動かしても、非常ブレーキ指令は継続し、それだけで発進しない。ただし方向選択自体は変化するため、「完全に何も起きない」と表現するのは不正確である。

主ハンドルをPへ動かせても、戸閉めなど別の許可条件によって力行しない場合とは区別する。個々の電気的起動条件は本表で調査・確定したものではない。

## 6. その他の考慮事項

### 6.1 キー・抜取位置は24通りの外側の条件

東急の仕様には、EBとは別に主ハンドルの**抜取位置**がある。レバーサー切のときだけ抜取～非常間を操作でき、キー抜取り時の位置は主ハンドル抜取・逆転ハンドル切とされる。[S1：照号21(2)(3)]

従って「EB＋中で主ハンドルがロック」は、**B・N・P側へ動かせない**という意味である。抜取位置も含めて一切動かせないという説明にはしない。表は依頼されたEB・B・N・Pの範囲に限っている。

日立の特許にあるキーの入切条件は、その特許の従来例の説明であり、東急の抜取位置を含むキー操作と無条件に同一視しない。[S2]

### 6.2 ノッチの指定と実際の力は同じではない

- Pは力行指令であり、車速・勾配・抵抗などにかかわらず一定の加速度になることを意味しない。
- Bはブレーキ指令であり、全段で任意の勾配上の停止保持を保証するものではない。
- Nは主ハンドルからの力行・常用ブレーキ指令がない状態であり、定速維持や停止保持の指令ではない。
- Nでも、保安装置など別系統のブレーキまで解除されるとは限らない。
- B・Pの各段を一括した表であり、段ごとの力・圧力・加速度は調査対象外である。

これらは表の解釈上の注意であり、E233系・E235系固有の制御則を確定した記述ではない。

### 6.3 走行・停止でインターロックが変わるか

参考資料の該当操作条件は主ハンドル位置とレバーサー位置によって記載されている。停止しただけでB・N・P中のレバーサーロックが解除される、とは読まない。

一方で、速度を検知する追加条件がないことまでは確認できていない。走行中EBの扱いは※1の未確認範囲を残す。

### 6.4 メーカー・型式の調査結果

| 対象 | 確認結果 |
|---|---|
| 東急8500系の主幹制御器本体 | ワンハンドル採用は確認済み。メーカー・型式は今回未確認。[S1][S4] |
| E235系・横須賀／総武快速線向けの主幹制御器 | 東芝の納入発表あり。ただしインターロック条件の記載はない。[S3] |
| E233系・E235系の24通りを確定する仕様 | 今回は未確認 |

**主幹制御器（運転台のマスコン）と主制御器（主回路の制御装置）は別機器**である。床下機器のMMC-HTR形などのメーカー情報を、マスコン本体のメーカー情報として転用しない。

会話中に一度「東武8500系」と記載されたが、依頼者により「東急8500系」の入力誤りと訂正済み。東武8000系のMA-DF-12形に関する情報は、本表の根拠や東急のメーカー情報に含めない。

### 6.5 シミュレーションへ転用するときの境界

本資料はCATの実装方針を決定するものではない。転用する場合は、少なくとも以下を別々の状態・条件として検討する必要がある。

- 主ハンドルの物理位置と、その位置への移動可否。
- レバーサーの物理位置と、その位置への移動可否。
- 入力された指令と、車両制御が実際に受け付ける指令。
- 選択方向と、実際の速度・進行方向。
- キー、抜取位置、使用運転台、戸閉め、保安装置などの追加条件。

特に「操作を拒否して以前のハンドル位置を保持する」と「位置は変わるが出力を抑制する」は異なる挙動である。実車資料が不足する条件を実装で補う場合は、**実車確認済み仕様ではなくシミュレーション上の設計判断**と明記する。
