## 読む順序

会話開始・再開とhandoff準備では、必ず[会話引継ぎと開始の手引き](../workflow/会話引継ぎと開始の手引き.md)を参照します。

1. [AGENTS.md](../../AGENTS.md)を入口に、[詳細な作業規則](下書き・参考/ドキュメント構成の参考.md)、[ドキュメント管理手順](../workflow/ドキュメント管理手順.md)、[要求工学・AI分業方針](下書き・参考/CAT_REQUIREMENTS_ENGINEERING_WORKFLOW.md)を確認します。
2. [共通方針と責任分担](整理3/共通方針と責任分担.md)で、文書の位置付け・状態区分・共通責任を確認します。
3. [残課題と再開地点](整理3/残課題と再開地点.md)を確認し、今回の対象文書と、その「関連」に挙げた必要な文書を読みます。毎回全ファイルを読み込む必要はありません。
4. 根拠が必要なら[調査資料索引](整理3/調査資料索引.md)から調査報告を参照します。調査結果を採用決定として扱いません。
