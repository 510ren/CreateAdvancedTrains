# 01移行：初回確認問題

作成日：2026-11-18。対象：[01-handoff](01-handoff.md)の移行。製品の新しい相談番号ではない。期待回答はまだ読まない。

## 回答方法

[整理3の索引](../../整理3.md)から以下の分野本文へ進み、各項目の回答と根拠節を先に確定する。その後に01-handoffが案内する期待回答を開いて比較する。回答の書換えで最初の相違を消さず、補足・訂正と原因を分ける。既決・提案・未決・調査事実・実機未検証を区別する。

新チャット初回には、この4項目への回答と、事項1～59・利用者訂正の第三者確認を別枠で返す。正答だけで矛盾・競合・不足・不正確さの点検を代替しない。確認者名、実際に確認できるモデル名／ID・推論レベル・情報源を示し、取得できなければ取得不可とする。結果は利用者が旧チャットへ持ち帰るため判定待ちで停止し、ファイル変更・製品相談へ進まない。

## 1. 作業境界と通常の担当・設備条件

作業場所、作業段階、詳細の正本、保存済み・未決・未完了範囲を示した上で、次に答える。

- 車掌交代と同一人物の設備移動は、権限・占有・移動中の担当をどう扱うか。走行中の交代と、開扉・運転終了等の条件は同じか。
- ワンマン兼任者の車掌だけの解除・再取得で、既存の運転手／ATO担当と運転台選択値をどう扱うか。初回開始、標準のみの車掌機能不要編成、ツーマン設定との差は何か。
- 車掌専任と運転・兼任のマスコンキー条件は何か。
- 通常の運転形態変更で必要設備が不足・確認不能となった場合、いつ何を検証し、旧形態・権限をどうするか。組立時に担当者が不在の場合と設備不足、運用中の設備喪失をどう区別するか。

主な根拠：[ドア11.19](../乗務員とドアと停車保持.md#s-11-19)、[HUD11.9](../マスコン操作とHUD.md#s-11-9)・[11.32](../マスコン操作とHUD.md#s-11-32)、[残課題14.3](../残課題と再開地点.md#requirements-follow-up-31)。

## 2. ドアの対象・操作・自動化と不明の扱い

- Create単体とSteam ’n’ Rails併用時で、対象・除外・初期対応外モードと直接クリックの条件はどう異なるか。Wiki案内・挟み込み挙動について何が決定済みで何が未検証か。
- 自動開閉の初期値、設定変更できる担当、ATOとの関係、Create標準の自動開閉との責任分担は何か。相反する設定変更が古い表示から届く場合はどう扱うか。
- 状態を確認できないドアがある場合、新規の手動／自動開扉と開始済み開閉をどう区別するか。全閉・ロック・力行禁止・保持・既存の要復旧はどう判定するか。
- 操作盤OFFの間に手動・自動の閉扉が同じ待ちへ統合され、自動閉扉だけがOFFになった場合、手動由来の要求はどうなるか。明示再開、編成更新の前後、再読込では何を区別するか。

主な根拠：[ドア3.4](../乗務員とドアと停車保持.md#s-3-4)、[11.20～11.31](../乗務員とドアと停車保持.md#s-11-20)、[共通3.2](../共通方針と責任分担.md#s-3-2)。

## 3. 連結後の担当終了と状態不明の記録

- 非継続側の手動運転担当・車掌・ATO、継続側の設備が中間台になる場合を区別し、通常操作権・終了専用の利用・設備占有・外端移動・担当予約・時刻表進捗・発車条件を説明する。
- 制御上必要な終了処理が完了して旧画面だけ残る場合と、処理や保持を確認できない場合で違いは何か。終了専用状態での死亡・切断・距離超過と、実際の手動操縦担当喪失の違いは何か。
- 未完了の終了処理だけを別の人が引き継げる条件・権限範囲は何か。共有台の終了順序について、何が既決で何が事項60の未回答提案か。
- ドア状態不明が継続する二編成の経過時間が異なる場合、連結・分離・通常再読込で記録をどう継承するか。未読込中と、列車の処理は続くがドア情報だけ取れない時間は同じか。
- 通知条件成立時に担当者が一人または双方不在なら、その機会・実配信・後の担当取得をどう扱うか。一般の長時間待機通知、駅不一致通知との差は何か。

主な根拠：[HUDの43～50](../マスコン操作とHUD.md#coupling-duty-end)、[列車2.4](../列車構成とプロファイル.md#s-2-4)、[ドア不明記録](../乗務員とドアと停車保持.md#unknown-door-record)・[11.20](../乗務員とドアと停車保持.md#s-11-20)・[11.30](../乗務員とドアと停車保持.md#s-11-30)、[非常6.6](../非常制御と故障復旧.md#s-6-6)、[通知8.15](../共通方針と責任分担.md#s-8-15)。未回答の内容自体は[事項60の提案](01-handoff.md#matter-60)を確認する。
