### SpeakerControllerの構想を維持

- 各スピーカーをSpeakerControllerへ直接接続する。スピーカー同士の直接・連鎖リンク方式は採用しない。
- 音源をControllerへ設定し、Controllerへのレッドストーン入力、または列車のボタンから再生指令を送る。
- 接続済みスピーカーで同一音源を同期再生する構想。
- 接続距離・最大台数・所属・音源形式／配布・権限・再生競合・未読込・破壊時処理は未決定。旧リンク方式の64ブロックを新方式へ自動継承しない。

### 13.10 SpeakerControllerと発車メロディー（決定／実現方法は未調査）

**指定と接続**

- 各スピーカーをSpeakerControllerへ接続し、Controller設定音源を列車側ボタン／レッドストーン等で再生する。スピーカー同士のリンク方式は採用しない。
- Controllerはワールド内で一意の識別名を持つ。ディメンションをまたぐ重複不可、完全一致指定、初期はワイルドカードなし。時刻表のメロディー子条件で指定する。
- 設定は名前参照で、改名しても時刻表を自動更新しない。同名の交換機器は次の要求から利用できる。
- 受付後は具体機器と再生IDに結び付ける。再生・停止・終了通知を同じIDで照合し、交換先へ古い要求を再送せず、遅延した通知・停止で別再生や次手順を処理しない。
- 接続距離・台数・音源形式／配布・音量／可聴距離・権限・未読込管理は未決定。

**再生・停止と手順**

- 音源は停止までループする。一周終了だけで手順完了にしない。子条件で「手動停止まで待つ（無限）」または「指定時間で自動停止」を選べる。時間指定中も権限者の途中停止が可能。
- 再生指示とともに条件をControllerへ渡す。Controllerが実際の開始から計時し、条件終了で停止して終了通知を返す。列車側が同じタイマーを重複管理する方式ではない。
- 無限再生は列車側等から明示停止し、終了通知を待つ。停止指示送信だけで完了せず、対象IDの実停止確認で進める。
- 任意の時刻表条件までControllerへ解釈させる仕様ではなく、初期の受渡し対象は指定時間／無限。時間単位・低TPSの扱いは残課題。
- **再生中は、停止確認まで手順を先へ進めない。** スキップ・OR強制完了でも止めずに通過できない。先に再生停止を案内する。まだ再生していない使用中待ち等はスキップ可能。
- 旧「一曲の自然終了で完了」「途中停止は正常完了にならない」「スキップ後も再生を継続して進む」は変更済み。指定条件終了または有効な停止による終了を正常完了とする。
- ATO OFF・自動再生OFFだけでは開始済み再生を暗黙停止しない。先の合意で区別した再生停止操作を必要とする。時刻表編集・交換時に開始済み再生をどう終えるか、実際の列車移動まで抑止する範囲は未決定であり、手順完了条件と物理的発車禁止を混同しない。

**競合・再試行**

- 一台一再生。別要求は割込み・重ね再生せず「使用中」を返す。同一要求の重複は新規再生せず元の状態を返す。他列車の再生終了で自分の手順を完了しない。
- 自動再生ONのATOは必要性を確認し一定間隔で再試行する。Controller側に予約を積まず列車側で管理する。手順変更・スキップ・強制完了・ATO OFF・自動再生OFFで不要になれば再試行終了。
- 手動の再生操作が使用中なら理由を通知し、再操作を待つ。自動再試行はしない。
- 使用中は無人でも時間だけでスキップせず再試行。長時間待機はINTEROS経由で組立者へ通知し、毎試行で通知しない。
- 再試行は旧再生の終了済み／未開始を確認し、新ID・音源先頭から行う。指定時間も実開始から数え直す。不明のまま二重要求せず、使用中ならその待機規則に従う。

**終了・失敗・有人判定**

| 結果 | 扱い |
| --- | --- |
| 条件終了／有効な停止の終了通知 | 対応する手順を正常完了 |
| 再生の確認済み異常終了 | 下記の有人／無人ATO判断 |
| 指定先不在・音源未設定等の確認済み開始失敗 | 異常終了と同じ判断 |
| 使用中 | 再試行または手動再操作待ち |
| 状態不明・終了通知未確認 | 確認待ち。不存在・停止済みと推測せず自動スキップしない |

- ATO操作担当または車掌権限者がいれば有人。乗客・閲覧者だけでは有人にしない。
- **ATO有効かつ両担当不在**なら、確認済み異常終了／開始失敗の手順だけ自動スキップする。INTEROS経由で組立者へ列車名・Controller名・原因・自動スキップの旨をチャット通知。重複防止、オフライン未配信保存なし。
- 有人なら未完了で原因を表示し、再試行またはスキップを選ぶ。同名再設置だけで勝手に再生し直さない。音の異常だけで要復旧EBにはしない。
- 選択待ちで担当全員離脱した場合も、**ATO有効時だけ**自動スキップ。ATO無効で待機した場合、または待機中ATOを解除した場合は進めない。後からATO開始しても手動案内をそのままスキップせず、開始位置選択・ATO実行状態に従う。
- 自動処理確定時の担当状況で判断し、確定前に担当が参加すれば選択待ち。確定後の参加でスキップを巻き戻さない。
- 音の再生・停止・再試行は車掌権限（ワンマン兼任を含む）。進捗スキップ・強制完了はATO担当／権限のあるATOS利用者。両者が原因・手順を閲覧できるが、車掌だけでは進捗編集できない。
- 車掌だけが残る場合は有人扱いでも進捗変更権限を持たない。再試行は可能、スキップにはATO担当等が必要。この場合の案内・引継ぎ詳細は今後のUI整理対象。
- スキップで閉扉・信号・進路・安全条件を省略しない。再生終了通知の欠落、長期不明、Server再起動、現地／レッドストーン操作との接続は未決定。
