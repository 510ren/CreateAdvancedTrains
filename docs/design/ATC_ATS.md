# ATC / ATS

## Phase 8の役割

ATC/ATSは、信号・保護点・進路に基づく速度制約と非常制動候補を返す保安装置層である。
BrakingCurveの数学、TASCの駅停止、EBの状態遷移を所有しない。

## 基本方針

- ATC/ATSは対象ごとの保護位置・制限速度・有効状態をResolverへ返す。
- 停止保護対象は原則として対象位置の手前3 blocksを保護位置とする。
- B7安全側の予測停止位置が保護位置を超える場合、EB候補としてEmergencyBrakeControllerへ渡す。
- Createの実装済み信号・予約・経路の意味は、Create 6.0.8実ソースを確認してから利用する。
