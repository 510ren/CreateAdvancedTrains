# Signal

## Phase 8の役割

SignalControllerは、Create 6.0.8の信号・停止位置・予約状態を読み取り、CATの速度制約または
保護対象として表す。信号を直接書き換えたり、Createの予約・経路を独自に変更したりしない。

## 初期要件

- 停止信号では信号を越えないことを最優先とする。
- 停止位置の通常誤差は、信号手前1〜2 blocksを候補とする。信号を超える側の誤差は許容しない。
- B7予測で保護位置を超える場合は、ATC/ATS層を通じてEB候補へ渡す。

## 実装前調査

- Create信号のEdgePoint、予約、列車検知、停止要求の実ソース上の関係。
- 信号の種類と進行方向、複数信号・分岐時の採用規則。
- CATが観測するだけで、Create標準信号制御と競合しないこと。
