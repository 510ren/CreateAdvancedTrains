# 非常制動（EB）

## 役割

EBは通常の `targetSpeed = 0` 指示ではなく、常用制動とは別の非常状態として扱う。
非常制動の性能テーブル、発動判定、ロック、復旧を独立した責務にする。

## Phase 8で実装する方針

- 手動運転では専用操作によって発動する。
- 自動運転では、B7相当の常用最大制動を継続しても停止対象までに止まれない場合だけ
  自動発動を検討する。
- 停止信号を越えずに停止できない場合は、将来の自動EB判定候補である。
- 自動EB後は通常の自動運転へ自動復帰させず、プレイヤーによる復旧を要求する。
- 表示は「非常制動発動」とし、脱線とは区別する。
- 停止信号、ATC/ATS保護点、線路終端、前方プレイヤー等は対象の手前3 blocksを保護位置とする。
  B7安全側予測が保護位置を超える場合にEB候補とする。
- 駅停止は、B7を継続しても停止位置を10 blocks以上超える予測の場合だけEB候補とする。
  ±0.5 blocksの通常停止誤差だけではEBにしない。
- Navigation destinationの負距離はEBではなく、CAT独自の脱線相当安全ロックアウトとして別に扱う。

## 未確定事項

EB倍率、速度依存性能、プレイヤー検知の距離・判定頻度、厳密な状態遷移、レンチによる復旧対象、
列車位置変更をキャンセルする正確な条件は未確定である。Createの物理脱線と区別したCAT独自安全状態との
境界も、実装前に確定する必要がある。
