## 資料の位置付け

- `organize/整理3/`：現在の詳細本文。分割記録を除き、今後の合意を反映する更新先。
- `organize/調査関連/`：現在の検討で参照する調査報告・観察資料・画像。採用未決、未検証、調査当時の仕様に依存する内容も含む。
- `organize/整理1/`、`organize/整理2/`：現在の検討に至る過程の資料。過去の内容を現行の決定に優先させない。
- `workflow/`：合意済みの文書管理手順。`workflow/保存記録/`は正式配置前の固定保存版。
- `organize/下書き・参考/`：適用中の詳しい作業規則、要求工学方針など。管理手順の旧下書きは正式配置先への案内になっている。
- `organize/整理3/分割記録/`：2026-10-25の分割時点の保存・照合記録。現行本文と並行更新しない。
- `old/`：[旧開発資料の保管場所](old/README.md)。当時の決定、実装指示、実測ログを現行仕様として扱わない。

利用者の指示に従いdocs内の整理を先行し、その確認後、2026-10-25にAGENTS.mdと正式な管理手順を整備した。既存の詳しい作業規則と要求工学方針も引き続き参照する。

## 2026-10-25の整理

旧開発の決定・技術文書、空または見出しのみの文書、旧走行ログの計59ファイルを、元の相対配置と内容を保って[再構築前資料](old/再構築前資料/README.md)へ移動した。現在の整理3本文・調査報告・画像は移動していない。

旧技術文書には利用可能な調査内容が含まれるため保存している。再利用候補と確認が必要な箇所は文書台帳を参照する。内容が古いことだけで「全て誤り」「全て不要」とは判定していない。
